# USD-currency-converter-Pesos-Soles-Deais-

My first Python currency converter project!

## Description
A simple Python program that converts Colombian pesos, Peruvian soles, and Brazilian reais into US dollars.

## Features
- Accepts user input
- Converts three currencies into USD
- Calculates the combined total
- Displays the result to two decimal places

## Technologies
- Python 3

## What I Learned
- Variables
- User input using `input()`
- Type conversion using `int()`
- Mathematical operations
- F-strings and number formatting

**Note:** Exchange rates are fixed in the code and may differ from current rates.
